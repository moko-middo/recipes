# 鶏の酒蒸し

**2人分**

## 材料

| 材料 | 分量 | 材料 | 分量 |
|------|------|------|------|
| 鶏もも肉 or 鶏むね肉 | 1枚 | (A)醤油 | 大1 |
| 塩、胡椒 | 少々 | (A)酢 | 大1 |
| 酒 | 大1 | (A)ごま油 | 小1/2 |
| (A)玉葱 or 長ねぎ | 1/8 or 1/3 | (A)蒸し汁 | 大1 |
| (A)砂糖 | 大1/2 |  |  |

## 手順

1. 鶏肉は皮を取って一口大に切る
2. 内鍋に肉を入れ、塩、胡椒、酒を入れる
3. 手動→煮物を作る（混ぜない）→10分
4. 煮汁につけたまま冷ます。
5. タレの材料(A)を耐熱ボウルに入れ、ラップをふんわりとして600Wで1分

## ちゃんと版：材料

| 材料 | 分量 | 材料 | 分量 |
|------|------|------|------|
| 鶏もも肉 | 1枚（250g） | (A)しょうゆ | 大1 |
| 塩 | 小1/4 | (A)酢 | 大1 |
| 酒 | 大2 | (A)砂糖 | 大1/2 |
| 長ねぎ（青い部分） | 1本分 | (A)ごま油 | 小1 |
| しょうが（薄切り） | 3枚 | (A)蒸し汁 | 大1 |
| (A)長ねぎ（みじん切り） | 1/3本 |  |  |

## ちゃんと版：手順

1. 鶏肉に塩をすり込み、10分おく
2. フライパンに鶏肉、ねぎの青い部分、しょうがをのせ、酒をふる
3. ふたをして中火にかけ、沸騰したら弱火で8分蒸す
4. 火を止め、ふたをしたまま10分おいて余熱で火を通す
5. (A)を混ぜてねぎだれを作る
6. 鶏肉を食べやすく切り、ねぎだれをかける
