# 鶏の酒蒸し

**2人分**

## 材料

| 材料 | 分量 | 材料 | 分量 |
|------|------|------|------|
| 鶏もも肉 or 鶏むね肉 | 1枚 | (A)醤油 | 大1 |
| 塩、胡椒 | 少々 | (A)酢 | 大1 |
| 酒 | 大1 | (A)ごま油 | 小1/2 |
| (A)玉葱 or 長ねぎ | 1/8 or 1/3 | (A)蒸し汁 | 大1 |
| (A)砂糖 | 大1/2 |  |  |

## 手順

1. 鶏肉は皮を取って一口大に切る
2. 内鍋に肉を入れ、塩、胡椒、酒を入れる
3. 手動→煮物を作る（混ぜない）→10分
4. 煮汁につけたまま冷ます。
5. タレの材料(A)を耐熱ボウルに入れ、ラップをふんわりとして600Wで1分
