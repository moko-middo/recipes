# 長ネギの肉巻き

**2人分**

## 材料

| 材料 | 分量 | 材料 | 分量 |
|------|------|------|------|
| 長ねぎ（白い部分） | 2本分 | 塩こしょう | 少々 |
| プロセスチーズ（キューブ） | 1個 | サラダ油 | 小1 |
| 豚バラ薄切り | 4枚 |  |  |

## 手順

1. 長ねぎの白い部分を7cmくらいの長さに切り、4本にする
2. ねぎのいちばん内側の芯を抜き取る
3. チーズを4つに切り、ねぎの穴に1個ずつ入れる
4. 豚バラ肉でくるくる巻く
5. フライパンに油を熱し、転がしながら焼く
6. 塩こしょうをふる

## ちゃんと版：材料

| 材料 | 分量 | 材料 | 分量 |
|------|------|------|------|
| 長ねぎ（白い部分） | 2本分 | サラダ油 | 小1 |
| プロセスチーズ（キューブ） | 1個 | (たれ)しょうゆ | 大1/2 |
| 豚バラ薄切り | 4枚 | (たれ)みりん | 大1/2 |
| 塩こしょう | 少々 | (たれ)酒 | 大1/2 |
| 小麦粉 | 少々 | (たれ)抜き取ったねぎの芯（みじん切り） | 全部 |

## ちゃんと版：手順

1. 長ねぎの白い部分を7cmくらいの長さに切り、4本にする
2. ねぎのいちばん内側の芯を抜き取り、芯はみじん切りにしてたれの材料と合わせる
3. チーズを4つに切り、ねぎの穴に1個ずつ入れる
4. 豚バラ肉で巻き、塩こしょうして小麦粉を薄くまぶす（肉がはがれにくく、たれがよくからむ）
5. フライパンに油を熱し、巻き終わりを下にして中火で焼く
6. 転がしながら全体に焼き色をつけ、ふたをして弱火で3分蒸し焼きにする
7. 出た脂をふき取り、たれを加えて照りが出るまで煮からめる
