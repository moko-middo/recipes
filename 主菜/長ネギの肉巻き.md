# 長ネギの肉巻き

**2人分**

## 材料

| 材料 | 分量 | 材料 | 分量 |
|------|------|------|------|
| 長ねぎ（白い部分） | 2本分 | 塩こしょう | 少々 |
| プロセスチーズ（キューブ） | 4個 | サラダ油 | 小1 |
| 豚バラ薄切り | 6枚 |  |  |

## 手順

1. 長ねぎの白い部分を7cmくらいの長さに切る（15個くらいになる）
2. ねぎのいちばん内側の芯を抜き取る
3. チーズを1個につき4つに切り（16個になる）、ねぎの穴に1個ずつ入れる
4. 豚バラ肉を半分に切って12枚にし、ねぎをくるくる巻く（巻けずに余ったねぎは一緒に焼く）
5. フライパンに油を熱し、転がしながら焼く
6. 塩こしょうをふる

## ちゃんと版：材料

| 材料 | 分量 | 材料 | 分量 |
|------|------|------|------|
| 長ねぎ（白い部分） | 2本分 | サラダ油 | 小1 |
| プロセスチーズ（キューブ） | 4個 | (たれ)しょうゆ | 大1 |
| 豚バラ薄切り | 6枚 | (たれ)みりん | 大1 |
| 塩こしょう | 少々 | (たれ)酒 | 大1 |
| 小麦粉 | 少々 | (たれ)抜き取ったねぎの芯（みじん切り） | 全部 |

## ちゃんと版：手順

1. 長ねぎの白い部分を7cmくらいの長さに切る（15個くらいになる）
2. ねぎのいちばん内側の芯を抜き取り、芯はみじん切りにしてたれの材料と合わせる
3. チーズを1個につき4つに切り（16個になる）、ねぎの穴に1個ずつ入れる
4. 豚バラ肉を半分に切って12枚にし、ねぎを巻く。塩こしょうして小麦粉を薄くまぶす（肉がはがれにくく、たれがよくからむ）
5. フライパンに油を熱し、巻き終わりを下にして中火で焼く
6. 転がしながら全体に焼き色をつけ、ふたをして弱火で3分蒸し焼きにする
7. 出た脂をふき取り、たれを加えて照りが出るまで煮からめる
