# トマトの肉巻き

**2人分**

## 材料

| 材料 | 分量 | 材料 | 分量 |
|------|------|------|------|
| トマト | 2個 | 塩 | 少々 |
| しゃぶしゃぶ用豚肉 | 200g | コショウ | 少々 |

## 手順

1. トマトをくし形に切る
2. トマトに肉をまき、塩こしょうする
3. 持ち手なし角型フライパンにのせ、下段、水位1以上
4. 30:ウォーターグリル（予熱無）→手動加熱→約26分→スタート

## ちゃんと版：材料

| 材料 | 分量 | 材料 | 分量 |
|------|------|------|------|
| トマト | 2個 | オリーブオイル | 小1 |
| しゃぶしゃぶ用豚肉 | 200g | ポン酢 | 大1 |
| 塩こしょう | 少々 | 粗びき黒こしょう | 少々 |
| 小麦粉 | 少々 |  |  |

## ちゃんと版：手順

1. トマトはへたを取り、8等分のくし形に切る
2. 豚肉で隙間なく巻き、塩こしょうして小麦粉を薄くまぶす
3. フライパンにオリーブオイルを熱し、巻き終わりを下にして中火で焼く
4. 転がしながら全体に焼き色をつける（トマトが崩れないよう手早く）
5. ポン酢を回しかけ、黒こしょうをふる
