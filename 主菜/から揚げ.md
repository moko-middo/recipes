# から揚げ

**2人分**

## 材料

| 材料 | 分量 | 材料 | 分量 |
|------|------|------|------|
| 鶏もも肉 | 250g | (A)しょうが | 2cm |
| (A) 鶏がらスープ | 小1 | (A)しょうゆ | 小1 |
| (A) 酒 | 小2 | 片栗粉 | 適量 |

## 手順

1. 鶏モモ肉を8等分する
2. (A)に漬け込み、20分以上置く
3. 片栗粉を付ける
4. 油を塗った網にのせ、下段、13:から揚げ、スタート

## ちゃんと版：材料

| 材料 | 分量 | 材料 | 分量 |
|------|------|------|------|
| 鶏もも肉 | 250g | (A)鶏がらスープの素 | 小1/2 |
| (A)しょうが（すりおろし） | 1かけ | 片栗粉 | 大2 |
| (A)にんにく（すりおろし） | 1/2かけ | 小麦粉 | 大1 |
| (A)しょうゆ | 大1 | 揚げ油 | 適量 |
| (A)酒 | 大1 |  |  |

## ちゃんと版：下ごしらえ

1. 鶏肉の余分な脂と筋を取り、8等分する
2. (A)をもみ込み、20分以上おく（つけ置く時間は所要時間に入っていません）

## ちゃんと版：手順

1. 片栗粉と小麦粉を合わせ、汁気を軽く切った鶏肉にまぶす
2. 170℃の油で3分揚げ、いったん取り出して3分休ませる
3. 190℃に上げた油で1分、カラッと二度揚げして油を切る
