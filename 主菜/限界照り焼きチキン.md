# 限界照り焼きチキン

**2人分**

## 材料

| 材料 | 分量 | 材料 | 分量 |
|------|------|------|------|
| 鶏もも | 230g | みりん | 大1 |
| 醤油 | 大1 | 砂糖 | 大1 |
| 酒 | 大1 |  |  |

## 手順

1. 鶏ももを1口大に切る。
2. 内鍋にすべての材料を入れる。
3. 手動→煮物を作る（まぜる）→20分でセット

## ちゃんと版：材料

| 材料 | 分量 | 材料 | 分量 |
|------|------|------|------|
| 鶏もも肉 | 1枚（230g） | (たれ)しょうゆ | 大1 |
| 塩 | 少々 | (たれ)みりん | 大1 |
| 小麦粉 | 少々 | (たれ)酒 | 大1 |
| サラダ油 | 小1 | (たれ)砂糖 | 大1/2 |

## ちゃんと版：手順

1. 鶏肉は筋を切り、厚い部分を開いて厚みをそろえる。塩をふり、小麦粉を薄くまぶす
2. フライパンに油を熱し、皮目を下にして弱めの中火で8分、へらで押さえながらパリッと焼く
3. 裏返してふたをし、弱火で3分焼く
4. 余分な脂をペーパーでふき取る
5. たれを加え、スプーンでかけながら照りが出るまで煮からめる
6. 食べやすく切り、たれをかける
