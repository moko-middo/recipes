# ピーマンの肉巻き

## 材料（2人分）

| 材料 | 分量 |
|------|------|
| ピーマン | 4個 |
| 豚バラ薄切り | 200g |
| とろけるスライスチーズ | 4枚 |
| 塩こしょう | 少々 |

---

## 仕込み

1. ピーマンにスライスチーズを1枚ずつ詰める
2. 豚バラで巻き、塩こしょうをする
3. 内鍋に水100mlを入れ、蒸しトレーにクッキングシートを敷く
4. 肉巻きを並べて冷蔵庫へ

---

## 帰宅後

### ホットクック

手動 → 蒸す → 10分

### 魚焼きグリル

弱火7分 → 裏返して6分

## ちゃんと版：手順

1. ピーマンは縦に切り込みを入れて種を取り、丸めたチーズを詰める
2. 豚肉を巻きつけて塩こしょうし、小麦粉を薄くまぶす
3. フライパンを熱し（油なし）、巻き終わりを下にして中火で焼く
4. 転がしながら焼き、ふたをして弱火で5分蒸し焼きにする
5. 出てきた脂をふき取り、たれを加えて煮からめる
