# ピーマンの肉巻き

## 材料（2人分）

| 材料 | 分量 |
|------|------|
| ピーマン | 4個 |
| 豚バラ薄切り | 200g |
| とろけるスライスチーズ | 4枚 |
| 塩こしょう | 少々 |

---

## 仕込み

1. ピーマンにスライスチーズを1枚ずつ詰める
2. 豚バラで巻き、塩こしょうをする
3. 内鍋に水100mlを入れ、蒸しトレーにクッキングシートを敷く
4. 肉巻きを並べて冷蔵庫へ

---

## 帰宅後

### ホットクック

手動 → 蒸す → 10分

### 魚焼きグリル

弱火7分 → 裏返して6分
