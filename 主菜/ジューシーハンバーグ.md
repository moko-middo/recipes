# ジューシーハンバーグ

**2人分**

## 材料

| 材料 | 分量 | 材料 | 分量 |
|------|------|------|------|
| (A)豚ひき肉 | 200g | 卵 | 1個 |
| (A)塩こしょう | 少々 | (B)ケチャップ | 大3 |
| (A)マヨネーズ | 大1 | (B)ウスターソース | 大1 |
| 玉ねぎ | 1/2個 |  |  |

## 手順

1. 玉ねぎはみじん切りにする
2. 卵をといておく
3. ボウルにA、1、2を入れて混ぜ、小判型にととのえ、中央にくぼみを作る
4. 強火で3の表面に焼き色をつける。裏返して弱火にし、ふたをして6分蒸し焼く
5. 残った肉汁に、Bを入れてひと煮立ちさせ、ソースを作る

## ちゃんと版：材料

| 材料 | 分量 | 材料 | 分量 |
|------|------|------|------|
| (A)合いびき肉 | 200g | 卵 | 1/2個 |
| (A)塩 | 小1/4 | サラダ油 | 小1 |
| (A)こしょう・ナツメグ | 少々 | (B)赤ワイン | 大2 |
| 玉ねぎ | 1/2個 | (B)ケチャップ | 大2 |
| バター | 5g | (B)ウスターソース | 大1 |
| パン粉 | 大3 | (B)バター | 5g |
| 牛乳 | 大2 |  |  |

## ちゃんと版：下ごしらえ

1. 玉ねぎをみじん切りにし、バターで薄く色づくまで炒めて冷ます
2. パン粉を牛乳に浸しておく

## ちゃんと版：手順

1. ボウルにひき肉と塩を入れ、白っぽく粘りが出るまでよく練る
2. 玉ねぎ、パン粉、卵、こしょう、ナツメグを加えて混ぜる
3. 2等分し、手のひらに打ちつけて空気を抜き、小判形にして中央をくぼませる
4. フライパンに油を熱し、中火で2分焼き色をつける
5. 裏返して弱火にし、ふたをして8分蒸し焼きにする。竹串を刺して透明な肉汁が出たら取り出す
6. 残った肉汁に(B)を入れて少し煮詰め、ソースにする
