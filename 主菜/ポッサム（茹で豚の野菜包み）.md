# ポッサム（茹で豚の野菜包み）

**3人分**

## 材料

| 材料 | 分量 | 材料 | 分量 |
|------|------|------|------|
| 豚バラ肉（塊） | 1本 (400g) | (サムジャン)みそ | 大1 |
| (ゆで汁)塩 | 小1 | (サムジャン)ねぎ | 大1(みじん切り) |
| (ゆで汁)酒 | 1/2カップ | (サムジャン)コチュジャン | 小1 |
| (ゆで汁)ねぎ(青い部分) | 1本分 | (サムジャン)すりごま(白) | 小1 |
| (ゆで汁)しょうがの皮 | 1かけ分 | (サムジャン)砂糖 | 小1 |
| キャベツ | 1/4個 | (サムジャン)酢 | 小1 |
| 青じそ | 10枚 | (サムジャン)ごま油 | 少々 |
| 白菜キムチ | お好みで | | |

## 手順

1. フライパンを強火で熱し、豚肉を脂身の方から順に表面をサッと焼く。
2. 色が変わったら取り出して鍋に入れ、ゆで汁の材料を入れる。
3. 豚肉がかぶるくらいの水を加えて強火にかける。
4. 表面がグツグツしてきたら弱火にし、表面が静かに揺れるくらいの火加減で20〜30分間ゆでる。（途中で湯をたす）
5. 茹で上がったら取り出し、ゆで汁を浸した厚手のペーパータオルをかぶせて粗熱をとる。
6. 粗熱が取れたら、豚肉を横に4等分にし、さらに縦方向に繊維に沿って薄切りにする。
7. サムジャンの材料をすべて混ぜ合わせておく。
8. キャベツは芯をとって洗い、ラップに包んで電子レンジで3分ほど加熱し、そのまま置いて粗熱をとる。
9. 器に盛り、キャベツに青じそ、豚肉、白菜キムチ、サムジャンを好みの量だけのせて巻いて食べる。

## ちゃんと版：下ごしらえ

1. 豚肉に塩をすり込み、30分おく

## ちゃんと版：手順

1. フライパンで豚肉の表面を脂身から焼きつける
2. 鍋に豚肉とゆで汁の材料を入れ、かぶるくらいの水を加えて強火にかける
3. アクを取り、表面が静かに揺れる弱火で40分ゆでる（途中で湯を足す）
4. 火を止め、ゆで汁に浸けたまま20分おいて冷ます（しっとり仕上がる）
5. サムジャンの材料を混ぜる。キャベツは芯を取って1分ゆでる
6. 豚肉を5mm幅に切り、キャベツ、サンチュ、青じそ、キムチ、サムジャンと盛り合わせる
