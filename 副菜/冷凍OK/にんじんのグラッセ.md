# にんじんのグラッセ

## 材料

| 材料 | 分量 |
| --- | --- |
| にんじん | 1本 |
| バター | 10g |
| 砂糖 | 小さじ1 |
| 塩 | 少々 |

## 手順

1. にんじんを1cm幅の輪切りにする（大きければ半月切り）
2. 小鍋ににんじん・バター・砂糖・塩・水50mlを入れて中火にかける
3. 蓋をして5〜7分、水分が飛んでツヤが出たら完成

## ちゃんと版：材料

| 材料 | 分量 | 材料 | 分量 |
|------|------|------|------|
| にんじん | 1本 | 塩 | 少々 |
| バター | 10g | 水 | ひたひた（150ml） |
| 砂糖 | 小2 |  |  |

## ちゃんと版：手順

1. にんじんは1cm幅の輪切りにし、角を面取りする（煮崩れず、きれいに仕上がる）
2. 鍋ににんじん、水、バター、砂糖、塩を入れ、落としぶたをして弱めの中火で15分煮る
3. ふたを取り、鍋をゆすりながら煮詰めてツヤを出す
