# ピーマンと塩昆布炒め

**4人分**

## 材料

| 材料 | 分量 | 材料 | 分量 |
|------|------|------|------|
| ピーマン | 5個 | ごま油 | 小1 |
| 塩昆布 | 5g |  |  |

## 手順

1. ピーマンは千切りにする
2. 内鍋にすべての材料を入れる
3. 手動でつくる→炒める→2分
