# ピーマンのじゃこあえ

**4人分**

## 材料

| 材料 | 分量 | 材料 | 分量 |
|------|------|------|------|
| ピーマン | 5個 | 砂糖 | 小1/2 |
| ちりめんじゃこ | 15g | ごま油 | 小1 |
| 醤油 | 大1/2 |  |  |

## 手順

1. ピーマンは千切りにする
2. 内鍋にすべての材料を入れる
3. 065:ピーマンのじゃこあえ（15分）

## ちゃんと版：材料

| 材料 | 分量 | 材料 | 分量 |
|------|------|------|------|
| ピーマン | 5個 | 酒 | 小1 |
| ちりめんじゃこ | 15g | 砂糖 | 小1/2 |
| ごま油 | 小2 | しょうゆ | 大1/2 |

## ちゃんと版：手順

1. ピーマンはへたと種を取り、千切りにする
2. フライパンにごま油を熱し、じゃこを弱めの中火でカリッとするまで3分炒める
3. ピーマンを加えて強火で1分炒める
4. 酒、砂糖、しょうゆを加えてさっとからめる
