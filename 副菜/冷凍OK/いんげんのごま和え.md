# いんげんのごま和え

**4人分**

## 材料

| 材料 | 分量 | 材料 | 分量 |
|------|------|------|------|
| いんげん | 150g | 砂糖 | 小2 |
| 水 | 100ml | 醤油 | 小2 |
| すりごま | 大2 |  |  |

## 手順

1. 内鍋に水を入れ、蒸し板の上にいんげんをのせる
2. 手動でつくる→蒸す→5分

## ちゃんと版：材料

| 材料 | 分量 | 材料 | 分量 |
|------|------|------|------|
| いんげん | 150g | (和え衣)砂糖 | 小2 |
| 塩 | 少々 | (和え衣)しょうゆ | 小2 |
| (和え衣)白いりごま | 大2 | (和え衣)だし | 小1 |

## ちゃんと版：手順

1. いんげんはへたを切り、塩を入れた湯で2分ゆでて冷水にとる
2. 水気をふき、3〜4cm長さに切る
3. いりごまをすり鉢で半ずりにし、砂糖、しょうゆ、だしを混ぜる
4. いんげんを和える
