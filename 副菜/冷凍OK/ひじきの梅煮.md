# ひじきの梅煮

## 材料

| 材料 | 分量 |
| --- | --- |
| ひじき（乾燥） | 15g |
| 梅干し | 2個 |
| 醤油 | 大さじ1 |
| みりん | 大さじ1 |
| だし（またはだしの素＋水） | 150ml |

## 手順

1. ひじきを水で20分戻し、水気を切る
2. 梅干しは種を取り除き、たたいてペースト状にする
3. 小鍋にひじき・梅干し・醤油・みりん・だしを入れ中火にかける
4. 煮立ったら弱火にして10分、汁気が少なくなったら完成

## ちゃんと版：材料

| 材料 | 分量 | 材料 | 分量 |
|------|------|------|------|
| ひじき（乾燥） | 15g | (だし)かつお節 | 5g |
| 梅干し | 2個 | しょうゆ | 大1 |
| ごま油 | 小1 | みりん | 大1 |
| (だし)水 | 200ml | 白いりごま | 少々 |
| (だし)昆布 | 5cm |  |  |

## ちゃんと版：手順

1. ひじきをたっぷりの水で20分戻し、よく洗って水気を切る
2. 小鍋に水と昆布を入れて弱火にかけ、沸騰直前に昆布を出してかつお節を入れ、1分でこす
3. 梅干しは種を取ってたたく
4. 鍋にごま油を熱し、ひじきを2分炒める
5. だし150ml、梅干し、しょうゆ、みりんを加え、弱火で10分、汁気が少なくなるまで煮る
6. ごまをふる
