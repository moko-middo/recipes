# ブロッコリーのゴマ和え

## 材料

| 材料 | 分量 |
| --- | --- |
| ブロッコリー | 1/2株 |
| すりごま | 大さじ1 |
| 醤油 | 小さじ1 |
| 砂糖 | 小さじ1/2 |

## 手順

1. ブロッコリーを小房に分け、耐熱容器に入れ水大さじ1をふる
2. ラップして600W・3分加熱
3. 水気を切り、すりごま・醤油・砂糖をあえる

## ちゃんと版：材料

| 材料 | 分量 | 材料 | 分量 |
|------|------|------|------|
| ブロッコリー | 1/2株 | しょうゆ | 小1 |
| 塩 | 少々 | 砂糖 | 小1/2 |
| 白いりごま | 大1 |  |  |

## ちゃんと版：手順

1. ブロッコリーは小房に分け、茎は皮を厚くむいて薄切りにする
2. 塩を入れた湯で1分半ゆで、ざるに広げて冷ます（水にとらない）
3. いりごまをすり鉢でする
4. すりごま、しょうゆ、砂糖でブロッコリーを和える
