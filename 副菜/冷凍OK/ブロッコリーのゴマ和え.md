# ブロッコリーのゴマ和え

## 材料

| 材料 | 分量 |
| --- | --- |
| ブロッコリー | 1/2株 |
| すりごま | 大さじ1 |
| 醤油 | 小さじ1 |
| 砂糖 | 小さじ1/2 |

## 手順

1. ブロッコリーを小房に分け、耐熱容器に入れ水大さじ1をふる
2. ラップして600W・3分加熱
3. 水気を切り、すりごま・醤油・砂糖をあえる
