# 青菜と油揚げの炒め物

## 材料

| 材料 | 分量 |
| --- | --- |
| 小松菜（またはチンゲン菜） | 1束 |
| 油揚げ | 1枚 |
| 醤油 | 小さじ2 |
| みりん | 小さじ1 |

## 手順

1. 青菜を3cm幅に切る。油揚げは短冊切りにする
2. フライパンで油揚げを中火で1分炒める
3. 青菜を加えてさっと炒め、醤油・みりんで味付けする
