# 青菜と油揚げの炒め物

## 材料

| 材料 | 分量 |
| --- | --- |
| 小松菜（またはチンゲン菜） | 1束 |
| 油揚げ | 1枚 |
| 醤油 | 小さじ2 |
| みりん | 小さじ1 |

## 手順

1. 青菜を3cm幅に切る。油揚げは短冊切りにする
2. フライパンで油揚げを中火で1分炒める
3. 青菜を加えてさっと炒め、醤油・みりんで味付けする

## ちゃんと版：材料

| 材料 | 分量 | 材料 | 分量 |
|------|------|------|------|
| 小松菜 | 1束 | 酒 | 小1 |
| 油揚げ | 1枚 | しょうゆ | 小2 |
| ごま油 | 小1 | みりん | 小1 |

## ちゃんと版：手順

1. 油揚げに熱湯を回しかけて油抜きし、短冊切りにする
2. 小松菜は3cm幅に切り、茎と葉に分ける
3. フライパンにごま油を熱し、油揚げを中火で1分炒める
4. 茎を入れて1分炒め、葉を加えてさっと炒める
5. 酒、しょうゆ、みりんで味をつける
