# しいたけの佃煮

**4人分**

## 材料

| 材料 | 分量 | 材料 | 分量 |
|------|------|------|------|
| 生しいたけ | 6個 | 醬油 | 大1 |
| 酒 | 大1 | 砂糖 | 大1 |
| みりん | 大1 |  |  |

## 手順

1. 内鍋にすべての材料を入れる
2. 手動でつくる→煮物を作る（まぜる）→10分

## ちゃんと版：材料

| 材料 | 分量 | 材料 | 分量 |
|------|------|------|------|
| 生しいたけ | 6個 | 砂糖 | 大1 |
| しょうが（せん切り） | 1/2かけ | みりん | 大1 |
| しょうゆ | 大1 | 水 | 50ml |
| 酒 | 大1 |  |  |

## ちゃんと版：手順

1. しいたけは石づきを取り、薄切りにする
2. 小鍋にすべての材料を入れて中火にかける
3. 煮立ったら弱火にし、時々混ぜながら汁気がほぼなくなるまで15分煮る
