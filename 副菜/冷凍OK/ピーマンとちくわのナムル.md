# ピーマンとちくわのナムル

## 材料

| 材料 | 分量 |
| --- | --- |
| ピーマン | 3個 |
| ちくわ | 2本 |
| ごま油 | 小さじ1 |
| 醤油 | 小さじ1 |
| 白ごま | 少々 |

## 手順

1. ピーマンをヘタと種を取り、細切りにする
2. 耐熱容器に入れラップして600W・1分30秒加熱
3. ちくわを薄切りにする
4. 水気を切ったピーマン・ちくわ・ごま油・醤油・ごまをあえる

## ちゃんと版：材料

| 材料 | 分量 | 材料 | 分量 |
|------|------|------|------|
| ピーマン | 3個 | 鶏がらスープの素 | 小1/4 |
| ちくわ | 2本 | しょうゆ | 小1 |
| ごま油 | 小1 | 白いりごま | 少々 |
| にんにく（すりおろし） | 少々 |  |  |

## ちゃんと版：手順

1. ピーマンはへたと種を取り、細切りにする。ちくわは斜め薄切りにする
2. フライパンにごま油とにんにくを熱し、ピーマンを強火で1分炒める
3. ちくわを加えてさっと炒め、鶏がらスープの素としょうゆで味をつける
4. ごまをふる
