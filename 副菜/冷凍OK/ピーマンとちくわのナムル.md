# ピーマンとちくわのナムル

## 材料

| 材料 | 分量 |
| --- | --- |
| ピーマン | 3個 |
| ちくわ | 2本 |
| ごま油 | 小さじ1 |
| 醤油 | 小さじ1 |
| 白ごま | 少々 |

## 手順

1. ピーマンをヘタと種を取り、細切りにする
2. 耐熱容器に入れラップして600W・1分30秒加熱
3. ちくわを薄切りにする
4. 水気を切ったピーマン・ちくわ・ごま油・醤油・ごまをあえる
