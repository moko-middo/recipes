# オクラと梅干しの和え物

## 材料

| 材料  | 分量       |
| --- | -------- |
| オクラ | 1袋（100g） |
| 梅干し | 1個       |


## 手順

1. オクラを1分ゆでる
2. ヘタを切り落として0.5cm幅の輪切りにする
3. 梅干しは種を取り除き、包丁でたたいてペースト状にする
4. オクラと梅干しをあえる

## ちゃんと版：材料

| 材料 | 分量 | 材料 | 分量 |
|------|------|------|------|
| オクラ | 1袋（100g） | みりん | 小1/2 |
| 塩 | 少々 | かつお節 | 少々 |
| 梅干し | 1個 |  |  |

## ちゃんと版：手順

1. オクラに塩をまぶし、まな板の上で転がして板ずりし、うぶ毛を取る
2. がくをぐるりとむき、塩がついたまま1分ゆでて冷水にとる
3. 0.5cm幅の輪切りにする
4. 梅干しは種を取ってたたき、みりんでのばす
5. オクラ、梅、かつお節を和える
