# オクラと梅干しの和え物

## 材料

| 材料  | 分量       |
| --- | -------- |
| オクラ | 1袋（100g） |
| 梅干し | 1個       |


## 手順

1. オクラを1分ゆでる
2. ヘタを切り落として0.5cm幅の輪切りにする
3. 梅干しは種を取り除き、包丁でたたいてペースト状にする
4. オクラと梅干しをあえる
