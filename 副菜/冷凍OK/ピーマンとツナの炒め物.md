# ピーマンとツナの炒め物

## 材料

| 材料     | 分量   |
| ------ | ---- |
| ピーマン   | 4個   |
| ツナの水煮  | 1袋   |
| 鶏ガラスープ | 小さじ1 |

## 手順

1. ピーマンをヘタと種を取り、細切りにする
2. ピーマンを1分ゆでる
3. ツナと鶏がらスープを加えて混ぜ合わせる

## ちゃんと版：材料

| 材料 | 分量 | 材料 | 分量 |
|------|------|------|------|
| ピーマン | 4個 | 酒 | 小1 |
| ツナの水煮 | 1袋 | 鶏ガラスープの素 | 小1/2 |
| ごま油 | 小1 | こしょう | 少々 |

## ちゃんと版：手順

1. ピーマンはへたと種を取り、縦に細切りにする
2. フライパンにごま油を熱し、ピーマンを強火で1分炒める
3. 汁気を切ったツナ、酒、鶏ガラスープの素を加えて炒め合わせる
4. こしょうで味をととのえる
