# ピーマンとツナの炒め物

## 材料

| 材料     | 分量   |
| ------ | ---- |
| ピーマン   | 4個   |
| ツナの水煮  | 1袋   |
| 鶏ガラスープ | 小さじ1 |

## 手順

1. ピーマンをヘタと種を取り、細切りにする
2. ピーマンを1分ゆでる
3. ツナと鶏がらスープを加えて混ぜ合わせる
