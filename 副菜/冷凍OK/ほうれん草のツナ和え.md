# ほうれん草のツナ和え

## 材料

| 材料 | 分量 |
| --- | --- |
| ほうれん草 | 1束 |
| ツナの水煮 | 1袋 |
| 醤油 | 小さじ1 |

## 手順

1. 鍋にお湯を沸かし、ほうれん草を根元から1〜2分ゆでる
2. 冷水にとって水気をよく絞り、3cm幅に切る
3. ツナ・醤油と和える

## ちゃんと版：材料

| 材料 | 分量 | 材料 | 分量 |
|------|------|------|------|
| ほうれん草 | 1束 | しょうゆ | 小1 |
| 塩 | 少々 | だし | 小2 |
| ツナの水煮 | 1袋 | 白すりごま | 小1 |

## ちゃんと版：手順

1. ほうれん草を塩ゆでし（根元30秒→全体30秒）、冷水にとる
2. 水気をしっかり絞り、3cm幅に切る
3. しょうゆとだしをかけて軽く絞る（しょうゆ洗いで水っぽくならない）
4. 汁気を切ったツナ、すりごまで和える
