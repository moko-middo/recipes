# ほうれん草のツナ和え

## 材料

| 材料 | 分量 |
| --- | --- |
| ほうれん草 | 1束 |
| ツナの水煮 | 1袋 |
| 醤油 | 小さじ1 |

## 手順

1. 鍋にお湯を沸かし、ほうれん草を根元から1〜2分ゆでる
2. 冷水にとって水気をよく絞り、3cm幅に切る
3. ツナ・醤油と和える
