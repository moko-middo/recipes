# きんぴらごぼう

**4人分**

## 材料

| 材料 | 分量 | 材料 | 分量 |
|------|------|------|------|
| ごぼう | 100g | 酒 | 大1 |
| 人参 | 100g | 砂糖 | 小2 |
| しょうゆ | 大1 | ごま油 | 大1/2 |
| みりん | 大1 | ごま | 少々 |

## 手順

1. ごぼうはささがきにして水にさらしアク抜きをする
2. 人参は細切りにする
3. 内鍋にごま以外の材料を全て入れる
4. 手動でつくる→炒める→5分
5. ごまを入れ混ぜ合わせる

## ちゃんと版：材料

| 材料 | 分量 | 材料 | 分量 |
|------|------|------|------|
| ごぼう | 100g | みりん | 大1 |
| 人参 | 100g | 砂糖 | 小2 |
| 赤唐辛子（輪切り） | 少々 | しょうゆ | 大1 |
| ごま油 | 大1/2 | 白いりごま | 少々 |
| 酒 | 大1 |  |  |

## ちゃんと版：手順

1. ごぼうは包丁の背で皮をこそげ、ささがきにして水に5分さらし、水気を切る
2. 人参は細切りにする
3. フライパンにごま油と赤唐辛子を熱し、ごぼうを2分炒める
4. 人参を加えて1分炒め、酒、みりん、砂糖を加える
5. しょうゆを加え、汁気がなくなるまで炒め煮にする
6. ごまをふる
