# きんぴらごぼう

**4人分**

## 材料

| 材料 | 分量 | 材料 | 分量 |
|------|------|------|------|
| ごぼう | 100g | 酒 | 大1 |
| 人参 | 100g | 砂糖 | 小2 |
| しょうゆ | 大1 | ごま油 | 大1/2 |
| みりん | 大1 | ごま | 少々 |

## 手順

1. ごぼうはささがきにして水にさらしアク抜きをする
2. 人参は細切りにする
3. 内鍋にごま以外の材料を全て入れる
4. 手動でつくる→炒める→5分
5. ごまを入れ混ぜ合わせる
