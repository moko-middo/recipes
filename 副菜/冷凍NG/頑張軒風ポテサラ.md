# 頑張軒風ポテサラ

**4人分**

## 材料

| 材料 | 分量 | 材料 | 分量 |
|------|------|------|------|
| じゃがいも | 3個 | サラダ | 1パック |
| 明太子 | 1/2腹 | マヨネーズ | 大2 |
| 卵 | 1個 |  |  |

## 手順

1. ゆで卵を作る
2. じゃがいもをゆで、皮をむき、つぶす
3. 明太子の皮をむく
4. 1~3にマヨネーズを加えて混ぜる
5. 4とサラダを混ぜる
