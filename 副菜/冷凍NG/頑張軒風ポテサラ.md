# 頑張軒風ポテサラ

**4人分**

## 材料

| 材料 | 分量 | 材料 | 分量 |
|------|------|------|------|
| じゃがいも | 3個 | サラダ | 1パック |
| 明太子 | 1/2腹 | マヨネーズ | 大2 |
| 卵 | 1個 |  |  |

## 手順

1. ゆで卵を作る
2. じゃがいもをゆで、皮をむき、つぶす
3. 明太子の皮をむく
4. 1~3にマヨネーズを加えて混ぜる
5. 4とサラダを混ぜる

## ちゃんと版：材料

| 材料 | 分量 | 材料 | 分量 |
|------|------|------|------|
| じゃがいも | 3個 | きゅうり | 1本 |
| (下味)酢 | 小1 | 玉ねぎ | 1/8個 |
| (下味)塩 | 少々 | マヨネーズ | 大2 |
| 明太子 | 1/2腹 | こしょう | 少々 |
| 卵 | 1個 |  |  |

## ちゃんと版：手順

1. 卵を沸騰した湯で10分ゆで、冷水にとって殻をむき、粗く刻む
2. じゃがいもを皮ごと水からゆで、竹串が通ったら熱いうちに皮をむいてつぶす
3. 熱いうちに下味の酢と塩を混ぜ、冷ます
4. きゅうりは薄切りにして塩少々でもみ、水気を絞る。玉ねぎは薄切りにして水にさらし、水気を絞る
5. 明太子の皮を取ってほぐす
6. すべてをマヨネーズで和え、こしょうで味をととのえる
