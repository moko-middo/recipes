# じゃがいもの塩バター煮

## 材料

| 材料 | 分量 |
| --- | --- |
| じゃがいも | 2個 |
| バター | 10g |
| 塩 | 少々 |

## 手順

1. じゃがいもを皮をむいてひと口大に切る
2. 耐熱容器に入れ、ラップして600W・5分加熱（竹串がスッと通るまで）
3. 熱いうちにバター・塩をからめる

## ちゃんと版：材料

| 材料 | 分量 | 材料 | 分量 |
|------|------|------|------|
| じゃがいも | 2個 | バター | 10g |
| 水 | 200ml | 黒こしょう・パセリ | 少々 |
| 塩 | 小1/4 |  |  |

## ちゃんと版：手順

1. じゃがいもは皮をむいて一口大に切り、水に5分さらす
2. 鍋にじゃがいも、水、塩を入れ、ふたをして中火で10分煮る
3. ふたを取って水分をとばし、鍋をゆすって粉をふかせる
4. バターをからめ、黒こしょうとパセリをふる
