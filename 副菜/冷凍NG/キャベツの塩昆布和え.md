# キャベツの塩昆布和え

## 材料

| 材料 | 分量 |
| --- | --- |
| キャベツ | 3〜4枚 |
| 塩昆布 | ひとつまみ |
| ごま油 | 少々 |

## 手順

1. キャベツをひと口大にちぎり、耐熱容器に入れラップして600W・2分加熱
2. 水気を絞り、塩昆布・ごま油をあえる
