# もやしのナムル

## 材料

| 材料 | 分量 |
| --- | --- |
| もやし | 1袋 |
| ごま油 | 小さじ1 |
| 塩 | 少々 |
| 白ごま | 少々 |

## 手順

1. 耐熱容器にもやしを入れ、ラップして600W・2分加熱
2. 水気を切り、ごま油・塩・ごまをあえる

## ちゃんと版：材料

| 材料 | 分量 | 材料 | 分量 |
|------|------|------|------|
| もやし | 1袋 | (A)にんにく（すりおろし） | 少々 |
| (A)ごま油 | 小1 | (A)塩 | 少々 |
| (A)鶏がらスープの素 | 小1/4 | 白いりごま | 少々 |

## ちゃんと版：手順

1. もやしのひげ根を取る（シャキッとして口当たりがよくなる）
2. 沸騰した湯で1分ゆで、ざるに上げて水気をしっかり切る
3. 熱いうちに(A)で和え、ごまをふる
