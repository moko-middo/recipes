# もやしのナムル

## 材料

| 材料 | 分量 |
| --- | --- |
| もやし | 1袋 |
| ごま油 | 小さじ1 |
| 塩 | 少々 |

## 手順

1. 耐熱容器にもやしを入れ、ラップして600W・2分加熱
2. 水気を切り、ごま油・塩・ごまをあえる
