# ふんわりたまごとチンゲン菜のスープ

**2人分**

## 材料

| 材料 | 分量 | 材料 | 分量 |
|------|------|------|------|
| チンゲン菜 | 30g | 水 | 400cc |
| 卵 | 1個 | 塩 | ひとつまみ |
| コンソメ | 小2 |  |  |

## 手順

1. チンゲン菜を4cm幅に切る
2. チンゲン菜、コンソメ、水、塩を入れて中火で5分
3. 溶き卵を回しいれる
