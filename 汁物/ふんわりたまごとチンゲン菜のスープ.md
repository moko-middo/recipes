# ふんわりたまごとチンゲン菜のスープ

**2人分**

## 材料

| 材料 | 分量 | 材料 | 分量 |
|------|------|------|------|
| チンゲン菜 | 30g | 水 | 400cc |
| 卵 | 1個 | 塩 | ひとつまみ |
| コンソメ | 小2 |  |  |

## 手順

1. チンゲン菜を4cm幅に切る
2. チンゲン菜、コンソメ、水、塩を入れて中火で5分
3. 溶き卵を回しいれる

## ちゃんと版：材料

| 材料 | 分量 | 材料 | 分量 |
|------|------|------|------|
| チンゲン菜 | 30g | しょうが（せん切り） | 少々 |
| 卵 | 1個 | 片栗粉 | 小1 |
| 水 | 400ml | 水 | 小2 |
| コンソメ | 小2 | ごま油 | 少々 |
| 塩 | ひとつまみ |  |  |

## ちゃんと版：手順

1. チンゲン菜は4cm幅に切り、茎と葉に分ける
2. 鍋に水、コンソメ、塩、しょうがを入れて煮立て、茎→葉の順に入れて2分煮る
3. 水溶き片栗粉で軽くとろみをつける
4. 溶き卵を細く回し入れ、10秒待ってから大きく混ぜる
5. ごま油をたらす
