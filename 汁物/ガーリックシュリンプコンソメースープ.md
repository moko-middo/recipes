# ガーリックシュリンプコンソメースープ

**2人分**

## 材料

| 材料 | 分量 | 材料 | 分量 |
|------|------|------|------|
| えび | 8尾 | 水 | 400ml |
| 玉ねぎ | 1個 | 白ワイン | 50ml |
| にんにく | 2かけ | コンソメ | 小2 |
| パセリ | 10g | 塩、こしょう | 少々 |
| バター | 大2 |  |  |

## 手順

1. えびの背わたを取る
2. 玉ねぎとにんにくを切る
3. 材料をすべて鍋にいれる
4. カテゴリ→スープ→野菜スープ
