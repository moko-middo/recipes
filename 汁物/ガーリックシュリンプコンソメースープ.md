# ガーリックシュリンプコンソメースープ

**2人分**

## 材料

| 材料 | 分量 | 材料 | 分量 |
|------|------|------|------|
| えび | 8尾 | 水 | 400ml |
| 玉ねぎ | 1個 | 白ワイン | 50ml |
| にんにく | 2かけ | コンソメ | 小2 |
| パセリ | 10g | 塩、こしょう | 少々 |
| バター | 大2 |  |  |

## 手順

1. えびの背わたを取る
2. 玉ねぎとにんにくを切る
3. 材料をすべて鍋にいれる
4. カテゴリ→スープ→野菜スープ

## ちゃんと版：材料

| 材料 | 分量 | 材料 | 分量 |
|------|------|------|------|
| えび（殻付き） | 8尾 | 白ワイン | 50ml |
| 片栗粉・塩 | 少々 | 水 | 400ml |
| 玉ねぎ | 1個 | コンソメ | 小2 |
| にんにく | 2かけ | パセリ | 10g |
| バター | 大2 | 塩、こしょう | 少々 |

## ちゃんと版：手順

1. えびは殻をむいて背わたを取り（殻はとっておく）、片栗粉と塩でもみ洗いする
2. 玉ねぎは薄切り、にんにくとパセリはみじん切りにする
3. 鍋にバター半量を溶かし、えびの殻を炒めて香りを出す
4. 白ワインと水を入れて5分煮て、殻を取り出す（えびだし）
5. フライパンで残りのバターとにんにくを弱火にかけ、玉ねぎを加えて5分炒める
6. えびを加えて色が変わるまで炒め、えびだしの鍋に移す
7. コンソメを加えて5分煮て、塩こしょうで味をととのえ、パセリを散らす
