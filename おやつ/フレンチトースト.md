# フレンチトースト

**1人分**

## 材料

| 材料 | 分量 | 材料 | 分量 |
|------|------|------|------|
| 食パン | 1枚 | 砂糖 | 大2 |
| 卵 | 1個 | バター | 5g |
| 牛乳 | 100ml | バニラエッセンス | 少々 |

## 手順

1. 食パンは9等分に切る
2. 卵・牛乳・砂糖・バター・バニラエッセンスを混ぜ、ホットクックに入れる
3. 切った食パンを入れ、よく漬けたら裏返し、反対側も漬ける
4. 手動で作る→ケーキを焼く→30分

## ちゃんと版：材料

| 材料 | 分量 | 材料 | 分量 |
|------|------|------|------|
| 食パン（4枚切り） | 1枚 | (卵液)バニラエッセンス | 少々 |
| (卵液)卵 | 1個 | バター | 10g |
| (卵液)牛乳 | 100ml | メープルシロップか粉糖 | 適量 |
| (卵液)砂糖 | 大1 |  |  |

## ちゃんと版：下ごしらえ

1. 卵液の材料をよく混ぜる
2. 食パンを半分に切って卵液に浸し、冷蔵庫で一晩おく（途中で裏返す）（つけ置く時間は所要時間に入っていません）

## ちゃんと版：手順

1. フライパンにバターを弱火で溶かし、パンを入れる
2. ふたをして弱火で5分、裏返してさらに4分焼く
3. メープルシロップか粉糖をかける
