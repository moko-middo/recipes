# 肉うどん

**2人分**

## 材料

| 材料 | 分量 | 材料 | 分量 |
|------|------|------|------|
| 牛肉薄切り | 200g | (A)しょうゆ | 大２ |
| うどん | ２玉 | (A)顆粒和風だし | 小1 |
| 小葱 | 適量 | (B)水 | 800ml |
| (A)水 | 大2 | (B)しょうゆ | 大1と1/3 |
| (A)酒 | 大2 | (B)みりん | 大1と1/3 |
| (A)みりん | 大2 | (B)顆粒和風だし | 大1 |
| (A)砂糖 | 大2 | (B)塩 | 小1/4 |

## 手順

1. 肉を食べやすい大きさに切る
2. ホットクックに肉と(A)を入れ手動→煮物を作る（混ぜる）→5分
3. 小葱を切っておく
4. 鍋にうどんスープの(B)を入れ煮立たせる
5. うどんも入れて一煮立ちさせる
6. 器にうどん、スープ、肉、小葱をいれる

## ちゃんと版：材料

| 材料 | 分量 | 材料 | 分量 |
|------|------|------|------|
| 牛薄切り肉 | 200g | (A)水 | 大4 |
| ゆでうどん | 2玉 | (だし)水 | 900ml |
| 小ねぎ | 適量 | (だし)昆布 | 10cm |
| (A)しょうゆ | 大2 | (だし)かつお節 | 20g |
| (A)酒 | 大2 | (つゆ)薄口しょうゆ | 大2 |
| (A)みりん | 大2 | (つゆ)みりん | 大1と1/3 |
| (A)砂糖 | 大2 | (つゆ)塩 | 小1/4 |

## ちゃんと版：手順

1. 鍋に水と昆布を入れて30分おく（時間があれば）。弱火にかけ、沸騰直前に昆布を取り出す
2. かつお節を入れて2分煮て火を止め、こしてだしを取る
3. だしにつゆの材料を入れて温める
4. 牛肉は食べやすく切り、小鍋で(A)を煮立てたところに入れ、汁気が少なくなるまで甘辛く煮る
5. うどんを温めて器に入れ、つゆを注ぎ、牛肉と小口切りの小ねぎをのせる
