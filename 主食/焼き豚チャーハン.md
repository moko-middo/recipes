# 焼き豚チャーハン

**2人分**

## 材料

| 材料 | 分量 | 材料 | 分量 |
|------|------|------|------|
| ごはん | ２膳 | (A)しょうが | 少々 |
| 長ねぎ | 1/2本 | (A)鶏ガラの素 | 小1 |
| 焼き豚 | 100g | (A)しょうゆ | 大1 |
| 卵 | 2個 | (A)ごま油 | 大1 |
| (A)にんにく | 少々 | 塩こしょう | 少々 |

## 手順

1. 長ねぎをみじん切りにする
2. 卵を溶く
3. 焼き豚を1cmの角切りにする
4. 1,2,3をホットクックに入れ炒める→3分
5. 加熱後手でかき混ぜほぐす
6. ごはん、(A)を入れる
7. しっかり混ぜ合わせ、追加で炒める→3分
8. 味を見て塩こしょうする

## ちゃんと版：材料

| 材料 | 分量 | 材料 | 分量 |
|------|------|------|------|
| ごはん（温かいもの） | 2膳 | サラダ油 | 大1と1/2 |
| 卵 | 2個 | (A)鶏ガラの素 | 小1 |
| 焼き豚 | 100g | (A)塩こしょう | 少々 |
| 長ねぎ | 1/2本 | しょうゆ | 小2 |
| にんにく（みじん切り） | 1/2かけ | ごま油 | 小1 |
| しょうが（みじん切り） | 1/2かけ |  |  |

## ちゃんと版：手順

1. 長ねぎはみじん切り、焼き豚は1cm角に切る
2. ボウルで卵を溶き、ごはんを入れてよく混ぜておく（パラパラになる）
3. フライパンを煙が出るまで強火で熱し、油を入れる
4. 卵ごはんを入れ、へらで切るようにほぐしながら2分炒める
5. にんにく、しょうが、焼き豚、ねぎを加えてさらに炒め、(A)で味をつける
6. 鍋肌からしょうゆを回し入れ、ごま油で香りをつける
