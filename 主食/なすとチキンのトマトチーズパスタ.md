# なすとチキンのトマトチーズパスタ

**2人分**

## 材料

| 材料 | 分量 | 材料 | 分量 |
|------|------|------|------|
| 鶏もも | 200g | オリーブオイル | 大1 |
| ナス | 1本 | ピザ用チーズ | 60g |
| 玉ねぎ | 1/2個 | スパゲティ | 2人分 |
| カットトマト缶 | 200g | 黒こしょう | 少々 |
| (A)コンソメ顆粒 | 小1/2 | パセリ (乾燥) | 適量 |
| (A)塩こしょう | 少々 |  |  |

## 手順

1. ナスは1cm幅の半月切り、玉ねぎは薄切りにする
2. 鶏もも肉は一口大に切る
3. スパゲティをゆで、湯切りする
4. 中火で熱したフライパンにオリーブオイルをひき、1を炒める
5. 火が通ったらカットトマト缶、(A)を入れて中火で加熱しひと煮立ちさせる
6. ピザ用チーズと3を入れてよく絡め、器に盛って黒こしょうとパセリをかける

| 材料 | 分量 | 材料 | 分量 |
|------|------|------|------|
| 鶏もも肉 | 200g | (A)コンソメ顆粒 | 小1/2 |

| 玉ねぎ | 1/2個 | パスタのゆで汁 | 大3 |
| にんにく | 1かけ | ピザ用チーズ | 60g |
| オリーブオイル | 大2 | 粉チーズ | 大1 |
| 白ワイン | 大2 | 黒こしょう | 少々 |
| ホールトマト缶 | 200g | バジル（あれば） | 数枚 |

## ちゃんと版：手順

1. なすは1cm幅の半月切り、玉ねぎは薄切り、にんにくはつぶす
2. 鶏肉は一口大に切り、塩こしょうする
3. たっぷりの湯に塩（湯の1%）を入れ、スパゲティを表示より1分短くゆでる
4. フライパンにオリーブオイルとにんにくを入れて弱火で香りを出す
5. 鶏肉を皮目から焼き、なす、玉ねぎを加えて炒める
6. 白ワインを入れてアルコールを飛ばし、トマトをつぶしながら加え、(A)を入れて5分煮る
7. スパゲティとゆで汁を加えてよく混ぜ、ピザ用チーズを溶かしからめる
8. 器に盛り、粉チーズ、黒こしょう、バジルをのせる
