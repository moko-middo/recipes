# ハヤシライス

**4人分**

## 材料

| 材料 | 分量 | 材料 | 分量 |
|------|------|------|------|
| トマト(くし切り) | 3個 | 牛薄切り肉 | 300g |
| 玉ねぎ(薄切り) | 2個 | 白ワイン | 100mL |
| ハヤシライスソースルウ | 4皿分 |  |  |

## 手順

1. トマトをくし切りにする
2. 玉ねぎを薄切りにする
3. ホットクックに全材料を入れ、406:ハヤシライス65分

## ちゃんと版：材料

| 材料 | 分量 | 材料 | 分量 |
|------|------|------|------|
| 牛薄切り肉 | 300g | トマト | 3個 |
| 塩こしょう | 少々 | 白ワイン | 100ml |
| 小麦粉 | 大1 | 水 | 200ml |
| 玉ねぎ | 2個 | ハヤシライスソースルウ | 4皿分 |
| マッシュルーム | 1パック | ケチャップ | 大1 |
| バター | 10g | ウスターソース | 大1 |

## ちゃんと版：手順

1. 玉ねぎは薄切り、マッシュルームは薄切り、トマトはざく切りにする
2. 牛肉は一口大に切り、塩こしょうして小麦粉をまぶす
3. 鍋にバターを溶かし、玉ねぎを中火で茶色くなるまで15分炒める
4. 牛肉を加えて色が変わるまで炒め、マッシュルームを加える
5. 白ワインを入れて煮立て、トマトと水を加えてふたをし、弱火で15分煮る
6. 火を止めてルウを溶かし、ケチャップとウスターソースを加えて5分煮る
