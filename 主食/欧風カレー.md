# 欧風カレー

**4人分**

## 材料

| 材料 | 分量 | 材料 | 分量 |
|------|------|------|------|
| 赤唐辛子 | 1本 | バター | 10g |
| 玉ねぎ | 2個 | 牛肉 | 400g |
| 塩こしょう | 少々 | 赤ワイン | 100ml |
| (A)にんにく | 1片 | (B)しょうゆ | 小2 |
| (A)しょうが | 1片 | (B)はちみつ | 小2 |
| (A)にんじん | 1/2本 | (B)ローリエ | 2枚 |
| (A)セロリ | 1/2本 | カレールウ中辛 | 4皿分 |
| (A)水 | 200ml |  |  |

## 手順

1. 玉ねぎをくし切りにする
2. ホットクックに赤唐辛子（半分+種）、玉ねぎ（塩少々）を入れ、炒める5分
3. 牛肉を一口大に切り、塩こしょうをする
4. (A)をミキサーにかけ、香味ジュースを作る
5. バター、牛肉、赤ワイン、香味ジュースを入れ、炒める5分
6. (B)、カレールーを加え、63:ビーフカレー45分

## ちゃんと版：下ごしらえ

1. 牛肉を赤ワインに漬け、冷蔵庫で2時間〜一晩おく（つけ置く時間は所要時間に入っていません）
2. (A)をミキサーにかけ、香味ジュースを作る

## ちゃんと版：手順

1. 玉ねぎを薄切りにし、バター半量と赤唐辛子で、あめ色になるまで30分炒める
2. 牛肉の汁気をふき（漬けたワインはとっておく）、塩こしょうと小麦粉をまぶす
3. フライパンで残りのバターを熱し、牛肉の表面をしっかり焼きつけて鍋に移す
4. 漬けたワインをフライパンに入れて煮立て、うまみをこそげて鍋に加える
5. 香味ジュース、水、(B)を入れ、アクを取ってふたをし、弱火で1時間煮込む
6. 火を止めてルウを溶かし、弱火で10分煮る
