# 豚バラなすのつけうどん

**2人分**

## 材料

| 材料 | 分量 | 材料 | 分量 |
|------|------|------|------|
| なす | 2本 | めんつゆ(3倍濃縮) | 60ml |
| 豚バラ | 130g | ゆでうどん | 2玉 |
| 水 | 400ml |  |  |

## 手順

1. なすを乱切りにする
2. 豚肉を一口大に切る
3. 内鍋になす、豚肉、水とめんつゆをいれる
4. 蒸しトレイにクッキングシートをしいてうどんをいれる
5. 手動で作る→スープを作る（まぜない）→10分
6. うどんを水で冷やす

## ちゃんと版：材料

| 材料 | 分量 | 材料 | 分量 |
|------|------|------|------|
| なす | 2本 | (つけ汁)砂糖 | 小1 |
| 豚バラ | 130g | 長ねぎ | 1/3本 |
| サラダ油 | 大1 | うどん（冷凍） | 2玉 |
| (つけ汁)だし | 300ml | (薬味)しょうが（すりおろし） | 適量 |
| (つけ汁)しょうゆ | 大3 | (薬味)みょうが | 1個 |
| (つけ汁)みりん | 大3 |  |  |

## ちゃんと版：手順

1. なすは乱切り、豚肉は一口大、長ねぎは斜め切りにする
2. フライパンに油を熱し、なすを焼き色がつくまで焼く
3. 豚肉とねぎを加えて炒める
4. だしとしょうゆ、みりん、砂糖を加えて3分煮て、つけ汁にする
5. うどんをゆでて冷水でしめ、薬味を添えて、温かいつけ汁につけて食べる
