# 豚バラなすのつけうどん

**2人分**

## 材料

| 材料 | 分量 | 材料 | 分量 |
|------|------|------|------|
| なす | 2本 | めんつゆ(3倍濃縮) | 60ml |
| 豚バラ | 130g | ゆでうどん | 2玉 |
| 水 | 400ml |  |  |

## 手順

1. なすを乱切りにする
2. 豚肉を一口大に切る
3. 内鍋になす、豚肉、水とめんつゆをいれる
4. 蒸しトレイにクッキングシートをしいてうどんをいれる
5. 手動で作る→スープを作る（まぜない）→10分
6. うどんを水で冷やす
